# Advanced Thunderstore Webhooks
Are you tired of having so little control over your Thunderstore update channel?

Do you want to be able to filter those annoying packages that no one cares about?

Well that, and more, is available with Advanced Thunderstore Webhooks!


# Current Features
1) **_Regex_** filtering 
2) Unlimited Communities
3) DIY - No reaching out to Thunderstore

# Planned Features
1) Custom message builder
2) Easier web UI
3) Suggest things at https://github.com/Scyye/AdvancedThunderstoreWebhooks/issues/
